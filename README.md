# Michael's Portfolio

Personal portfolio site. Next.js (App Router) + TypeScript + Tailwind CSS v4.
Design lineage: brittanychiang.com — sticky sidebar, scroll-spy nav, dark
navy + teal accent, timeline rows and project cards with tech-tag pills.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

All site content lives in `lib/data.ts` — edit that file to update the
about text, experience, education, projects, and socials. No component
changes needed.

## Status

Local only. Not pushed to GitHub, not deployed. Michael approves the
repo and deployment separately.
