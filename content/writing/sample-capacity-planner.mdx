## Headings structure the post

Sections use `##` headings like this one. Subsections use `###`. Keep paragraphs short — recruiters skim.

## Code blocks

Fenced code blocks render in a dark panel:

```python
def required_capacity(peak_demand: float, headroom: float = 0.30) -> float:
    """Naive headroom model: provision peak demand plus a buffer."""
    return peak_demand * (1 + headroom)


print(required_capacity(100.0))  # 130.0
```

Inline code looks like `headroom = 0.30` inside a sentence.
